# ПЗ-1.2. Арифметика в системах числення

Консольна програма `praxe-1.2.py` реалізує алгоритми з частини 2 практичного заняття №1: арифметичні дії над числами в двійковій, вісімковій і шістнадцятковій системах.

## Запуск

```
python praxe-1.2.py
```

Потрібен Python 3.8 або новіший. Додаткові бібліотеки не потрібні.

## Меню

| Пункт | Дія |
|---|---|
| `1` | Додавання |
| `2` | Віднімання (стовпчиком) |
| `3` | Множення |
| `4` | Ділення |
| `5` | Віднімання через додатковий код (двійкова система) |
| `0` | Вихід |

Для пунктів 1–4 програма запитує основу системи (2, 8 або 16) і два числа.

## Реалізовані алгоритми

- **Додавання**: порозрядно від молодшого розряду, з урахуванням переносу.
- **Віднімання**: порозрядно, з позикою зі старшого розряду. Якщо перше число менше за друге, результат від'ємний.
- **Множення**: множення на кожну цифру множника, зсув і додавання часткових добутків.
- **Ділення**: у стовпчик, програма повертає частку та остачу.
- **Додатковий код**: `a − b` замінюється додаванням прямого коду `a` і додаткового коду `−b`. Одиниця переносу за розрядною сіткою відкидається.

Кожна дія виводить проміжні кроки та перевірку в десятковій системі.

## Приклад: ділення 101010 на 111 у двійковій системі

Меню `4`, основа `2`, перше число `101010`, друге число `111`.

<img width="500" alt="Ділення двійкових чисел" src="https://github.com/user-attachments/assets/7cfc3bad-b28e-45cd-b9a8-57d784d8aa93" />

Результат: частка `110(2)`, остача `0`. Перевірка: `42 : 7 = 6`.

## Інші приклади для перевірки

| Дія | Основа | Числа | Результат |
|---|---|---|---|
| Додавання | 2 | `1101` і `1110` | `11011` |
| Додавання | 16 | `FB` і `C6` | `1C1` |
| Додавання | 8 | `741` і `252` | `1213` |
| Віднімання | 2 | `11001` і `1101` | `1100` |
| Множення | 2 | `111` і `101` | `100011` |

## Обмеження

- Працює лише з цілими числами.
- Числа вводяться без знака. Від'ємний результат віднімання програма визначає сама.
