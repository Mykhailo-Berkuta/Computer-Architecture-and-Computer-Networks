# ПЗ-1.1. Системи числення та коди чисел

Консольна програма `praxe-1.1.py` реалізує алгоритми з частини 1 практичного заняття №1: переведення чисел між системами числення та побудову прямого, зворотного й додаткового кодів.

## Запуск

```
python praxe-1.1.py
```

Потрібен Python 3.8 або новіший. Додаткові бібліотеки не потрібні.

## Меню

| Пункт | Дія |
|---|---|
| `1` | Переведення між системами 2 / 8 / 10 / 16 |
| `2` | Прямий, зворотний і додатковий коди числа −n |
| `0` | Вихід |

## Реалізовані алгоритми

- **Метод ділення**: переведення цілої частини з десяткової системи. Число ділиться на основу, залишки записуються від останнього до першого.
- **Метод множення**: переведення дробової частини. Дробова частина множиться на основу, цілі частини дають цифри результату.
- **Переведення в десяткову**: за формулою полінома, сума `цифра * основа^позиція`.
- **Коди чисел**: прямий (знаковий розряд + модуль), зворотний (інверсія розрядів модуля), додатковий (зворотний + 1). Розрядна сітка кратна 8.

Після кожного переведення програма виконує зворотне переведення для перевірки.

## Приклад: переведення 197 з десяткової в двійкову

Меню `1`, число `197`, вихідна основа `10`, цільова основа `2`.

## Приклад: коди числа
