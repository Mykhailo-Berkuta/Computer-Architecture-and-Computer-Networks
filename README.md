# Архітектура комп'ютера та комп'ютерних мереж

Практичні та лабораторні роботи з дисципліни «Архітектура комп'ютера та комп'ютерних мереж» (ХНУРЕ, 2 курс, 3 семестр).

**Автор:** Mykhailo Berkuta

## Зміст

| Робота | Тема | Опис |
|---|---|---|
| [ПЗ-1.1](ПЗ-1/ПЗ-1.1/) | Системи числення та коди чисел | [README](ПЗ-1/ПЗ-1.1/README-1.1.md) |
| [ПЗ-1.2](ПЗ-1/ПЗ-1.2/) | Арифметика в системах числення | [README](ПЗ-1/ПЗ-1.2/README-1.2.md) |

## Структура репозиторію

```
ПЗ-1/
├── ПЗ-1.1/    praxe-1.1.py, README-1.1.md, screenshots/
└── ПЗ-1.2/    praxe-1.2.py, README-1.2.md, screenshots/
```

У кожній папці лежить код програми, опис алгоритмів і скриншоти прикладів.

## Запуск

Потрібен Python 3.8 або новіший. Додаткові бібліотеки не потрібні.

```
python praxe-1.1.py
```

Запускайте команду з папки відповідної роботи.
