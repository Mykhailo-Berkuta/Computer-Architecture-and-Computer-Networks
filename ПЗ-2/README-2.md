# ПЗ-2. Дослідження структури та параметрів персонального комп'ютера

Програма `praxe-2.py` (самостійна робота) визначає характеристики обчислювальної системи за допомогою системних та бібліотечних викликів і заповнює таблицю 2.3 з методичних вказівок.

## Запуск

```
python praxe-2.py
```

- Потрібні Windows і Python 3.8 або новіший.
- Додаткові бібліотеки не потрібні.
- Збір даних займає кілька секунд.
- Звіт виводиться на екран і зберігається у файл `system_report.txt` поруч зі скриптом.

## Які виклики використано

| Джерело | Що отримуємо |
|---|---|
| `GetSystemInfo` (WinAPI, `ctypes`) | Архітектура, кількість логічних процесорів, маска процесорів, розмір сторінки пам'яті, діапазон адрес |
| `GlobalMemoryStatusEx` (WinAPI) | Обсяг, вільна пам'ять і завантаження ОП |
| `RtlGetVersion` (WinAPI) | Точна версія та збірка Windows |
| `GetSystemTimes` (WinAPI) | Поточне завантаження процесора |
| Реєстр Windows (`winreg`) | Модель, частота, виробник процесора |
| WMI (через PowerShell) | Плата, BIOS, модулі й слоти пам'яті, диски, відеокарта, звук, мережа, кеш, слоти розширення |
| `platform`, `socket`, `shutil`, `os` | Ім'я комп'ютера, IP-адреса, обсяг розділів дисків |

## Розділи звіту

1. Операційна система
2. Процесор (включно з кешем і завантаженням)
3. Оперативна пам'ять (модулі, тип, слоти)
4. Системна плата, BIOS, чипсет
5. Накопичувачі
6. Відеоадаптер, звук, мережеві адаптери
7. Слоти розширення
8. Підсумкова таблиця 2.3

## Обмеження

- Форм-фактор плати (ATX, mATX тощо) Windows не повідомляє, тому програма показує тип корпусу (Desktop, Laptop).
- Чипсет визначається приблизно, за назвами системних пристроїв.
- Обсяг пам'яті відеокарти WMI обмежує 4 ГБ.
- На ноутбуках список слотів розширення часто порожній, бо BIOS не передає цих даних.
- Програма працює лише на Windows. На інших системах виводить коротку інформацію й завершується.
